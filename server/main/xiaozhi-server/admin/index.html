下载本次试听音频

原始试听与 Opus 还原可分别下载，再导入 ESP32 网页对比播放。两者都正常而对话卡顿时，重点看 ESP32 的“对话音频诊断”。试听在当前浏览器播放；切换后点击下方“保存并应用”，设备对话才会使用所选方式。设备网络、音量和麦克风在 ESP32 网页设置。

API Key 保存在本机配置中，页面只显示是否已配置，不会读回密钥。

连续对话

开启后按一次键就能说，说完不用再按，服务端听出你说完了就回答；她回答完会接着听你说。一段时间没听到你说话就停下，等你下次按键。关闭时和现在一样：按一次开始、再按一次发送。设备没有回声消除，她说话时不能插话打断，要打断请按键。

无论是否开启，鲸鱼娘问“歌练好了，要不要现在听？”这类问题时，都会自动听你的回答。

会话上下文

默认恢复同一设备及 Client ID 在最近 24 小时内的 6 轮完整对话，最多 6000 字；0 表示不恢复。同一次连接内仍有上下文。对话记录与模型长期记忆是不同功能。

鲸鱼娘的系统提示词

设定角色、说话风格和回答习惯。提示词决定行为规则，MCP 工具定义决定实际能力。

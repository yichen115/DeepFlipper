DFDeepFlipperESP32 设备设置
开始设置

连接你的鲸鱼娘。

首次登录使用 Flipper 的 AI Assistant 中 Setup: 开头的一项里显示的 AP pass。这里设置设备网络；模型 API 在 Python 服务端网页设置。

忘记管理密码？

设备正常上电后，长按 ESP32 对话按钮 5 秒：开启恢复热点，并将网页密码恢复为 Flipper 显示的 AP pass。不要按住按钮上电。

01 · 网络

连接家庭 Wi-Fi

ESP32-S3 使用 2.4 GHz Wi-Fi。扫描选择网络，也可以手动填写名称。

只有拿到 IP 后才保存新网络。成功后热点约 15 秒关闭；将手机切回家庭 Wi-Fi，按 Flipper 显示的新地址继续访问。

02 · 服务端

连接语音服务器

将设备身份导入 Python 管理页，生成连接配置，再导入这里。也可以直接粘贴地址和 Token。

尚未设置

本地服务填电脑的局域网 IP，不能填 localhost / 127.0.0.1。测试认证不会打开麦克风；认证通过后仍需测试实际语音。

03 · 声音与灯光

让她回应你

声音测试需要已连接并启用 Flipper AI session。听到提示音才表示喇叭链路可用。

管理

修改网页登录密码

修改的是网页登录密码，热点仍使用 Flipper 显示的设备专属 AP password。Wi-Fi 密码和 Token 均不回显。

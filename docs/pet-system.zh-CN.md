# 鲸鱼娘宠物系统：第一版与后续计划

第一版优先角色外观、动作和及时回应。保留现有蓝发鲸鱼娘的单色像素造型，用户提供的
“吃白饭的大肥鱼”图片作为性格与饭碗参考：最喜欢白米饭。对战、好友和外设道具暂不做。

## 已实现的第一版

`Whale Pet` 是从 SD 加载的外部应用，位于 `Applications → Games`。
默认模式下，主页短按右键也可进入；系统警告或升级动画出现时，右键先确认当前提示。

主页只展示房间、角色动画和少量状态，不承接喂饭、摸摸、玩球等照料操作。
AI 开启时短按 OK 聊天／发送录音，长按 OK 打开系统菜单；上下、左键和长按右键沿用原有入口。
宠物照料、数值和表情展览保留在 App 内。Dummy Mode 保留原有按键配置。
主固件保持原有桌面和手动工具；宠物代码、JSON 与动画表均随 FAP 加载，完整帧放在 SD，
避免进一步占用内部 Flash。它不替代已有 Dolphin 等级和 Passport 存档。

配套构建会生成完整更新 TGZ 和单独的 `WhalePet-sd-preview.zip`。已经使用匹配的
DeepFlipper SDK 88.25 固件时，可仅将预览 ZIP 中的 `apps/`、`deepflipper/` 合并到 SD 根目录；
ZIP 不包含宠物存档。其他固件/API 版本的兼容性未经确认，不应强行加载。

### 界面与操作（2026-11-15 改版：方案 B2）

App 画面是全屏房间：左上钉着的数值卡（饱腹／精力／开心三条）、左下玩具篮、右侧窗户和
摆着白米饭的餐桌，角色居中，用遮罩合成（白脸、白衣和 1 像素白边保留），不会和花纹背景糊在一起。
白天／夜晚房间按 07:00／20:00 切换。底部一次只显示一个带图标的英文动作。

| 操作 | 作用 |
|---|---|
| 左／右 | 切换底部动作：Pat、Feed、Play、Catch、Sleep、Stats；睡觉时只有 Wake、Stats |
| 短按 OK | 执行当前动作；Catch 进入 Catch Rice 小游戏，Stats 进入数值页 |
| 长按 OK | 直接进入数值页 |
| 数值页左／右 | 进入表情展览，左右翻看 19 组动作；返回回到数值页 |
| 短按返回 | 离开子页；在主画面退出 App；小游戏中提前结束并结算 |
| 长按返回 | 从任意页面退出 |

互动逻辑：

- **需求表达与默认项**：饱腹 < 40、精力 < 30、开心 < 40 时，她在待机变奏里冒 `Hungry...`／`Sleepy...`／`Play?`
  气泡并换成担心／犯困／好奇；深夜（23–5 点）精力 < 60 会提示 `Bedtime?`。打开 App、动作结束和
  待机变奏时，若 10 秒内没按左右，菜单自动停在最需要的一项。
- **看得见的结果**：成功保存后，按操作前后实际数值变化闪烁 `+`／`−`。玩球、接米粒的精力显示 `−`、开心增加时显示 `+`；喂饭增加的饱腹、精力、开心显示 `+`，已经满值而未变化的数值不显示加号。冷却 `Later~`、吃饱 `So full!`、太累 `Too tired`
  都会用气泡说明，不再假装加成生效。保存失败显示 `Not saved!` 和顶部提示。
- **动作播完再接下一个**：照料动画播放时底部菜单让开，只响应返回键，避免打断和连续写卡。
  只有真正改变状态的操作才写 SD，退出时再整体保存一次。
- **欢迎语**：离开超过 1 小时 `Welcome back!`，早上 `Morning!`，深夜 `Up late?`，其他 `Hi!`；睡着时 `Zzz...`。
- **连摸**：8 秒内连续摸摸：前两下 `Hehe~`，第 3–4 下害羞 `Heh...`，第 5 下起惊讶 `Hey!`；奖励仍按 60 秒冷却。
- **升级庆祝**：升级后在动作结束时播放兴奋动作和 `Lv.N!` 气泡；数值页有“距下一级”进度条。
- **自己醒来**：睡觉时精力恢复到 100 会自动醒来（菜单随之切回、冒 `Morning!`）。

### Catch Rice 小游戏

左半屏是游戏区，右半屏是她的反应（接到时兴奋，漏接时担心）。按住左右移动饭碗（每 50 ms 3 像素），
轻点一下也会挪 4 像素；饭碗 17 像素宽，判定比画面略宽松。偶尔掉落的饭团算 3 分。
同屏最多 3 粒，起始约 3 秒落地，最快约 1.6 秒。漏接普通米粒扣 1 颗心，5 颗心用完或 30 秒结束。
结算沿用玩耍规则：精力 < 25 不能开始；与玩球共用 120 秒冷却，冷却中可以玩但显示 `Just for fun`；
有效一局消耗 5 精力，开心 +6～16、经验 +2～8、亲密度 +3。

### 温和的成长

饱食、精力、心情为 0–100；亲密度至多 1000，经验至多 9999，五个成长等级。
摸摸每 60 秒、玩耍每 120 秒、吃饭每 300 秒可获得一次对应效果；重复摸摸仍有表情，
重复喂饭冷却期播放满足而不再次吃饭。饱食达到 95 后不再进食，精力低于 25 时建议休息。

每 10 分钟结算一次状态。醒着时精力每 10 分钟 -1、玩球／小游戏各 -5；睡觉时每 10 分钟 +15
（从 25 睡到满约 50 分钟），精力满 100 时自己醒来；每次成功喂饭额外 +6 精力。打开应用时会依据本机 RTC 补算离线变化，
最多补算六小时，饱食／精力／心情下降到 20 后不再下降。不会死亡、丢等级或抹掉亲密度，
不会因为几天没打开就惩罚用户。当前时间调整会影响冷却和离线结算；这是本机休闲养成，
不是可信竞技计分。状态尚未后台常驻，离线变化在打开或调用时计算。

### 存档

存档位于 `/ext/deepflipper/pet/state-a.bin` 和 `state-b.bin`。
采用明确的版本、长度、CRC32 和轮换编号，每次写另一份，sync 后读回验证，保留上一份。
某份被中断／损坏时加载另一份；两份都损坏时进入只读状态，不自动创建新宠物覆盖原文件。
丢失 SD 或保存失败时界面提示，RPC 返回错误，不报告保存成功。失败后磁盘结果可能不确定，
不要自动重复有奖励的照料动作。第一版会在互动和正常退出时保存；突然断电可能丢失最后
一次尚未完成的写入，硬件验证仍待进行。

每次保存成功后，App 额外写入只读的 `/ext/deepflipper/pet/home.bin`（"DFH2" + 最多 8 个
`{时间, 状态}`），按真实结算规则预测未来 48 小时何时睡着／醒来、饿、困、无聊。主页每约 5 秒读取一次，
显示当前该有的气泡（饭碗／Zzz／球），睡着时主页也播放睡觉动画；存档槽仍是唯一真实数据，主页从不写它。

动画文件 `/ext/deepflipper/pet_frames.bin` 和遮罩 `pet_masks.bin` 缺少时显示静态原始角色和提示，仍可退出。
应用线程读帧，GUI 回调只绘制内存快照；不在输入回调中写 SD，也不加载全部动画到 RAM。

## 语音端预留接口

配套更新包登记 `/ext/apps/Games/whale_pet.fap`，复用已有 app catalog／describe／call，
没有增加 ESP32 专用宠物工具。提供 `pet.state` 和 `pet.interact`，照料 kind 为
`pat`、`feed`、`play`、`rest`、`wake`，喂食固定为白米饭。例如：

```json
{
  "app":"/ext/apps/Games/whale_pet.fap",
  "action":"pet.interact",
  "arguments":"{\"kind\":\"feed\"}"
}
```

结果包含饱食、精力、心情、亲密度、经验、等级、睡眠、favorite_food、care_result、
effect_applied、saved、revision。`care_result:cooldown/full/asleep/tired` 的调用可以正常完成，
但 `effect_applied:false`，不能声称新增数值。两种入口使用同一份存档与规则。

**当前 RPC 照料只写入状态，不打开宠物界面，明确返回 `displayed:false`。**
手动打开宠物 FAP 会沿用已有 Loader 策略，暂停 AI UART、释放后台资源；退出后恢复。
所以本版可独立养宠，也能通过语音照料，但不支持在该手动 FAP 内连续语音聊天。
倾听、思考和说话动画现在可以在表情展览查看，尚未连接 App 内实时语音嘴型。
主页使用现有 12 组语音动画和实时嘴型，搭配日间／夜间房间；时间显示在闹钟屏幕、电量在电饭煲屏幕，
语音状态和宠物愿望用头顶小气泡表示；主页只读宠物预测文件，不会更改宠物存档。
